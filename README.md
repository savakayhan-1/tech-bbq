## Publish with GitHub Pages

1. Create a new public repository, for example `techbbq-plan`.
2. Upload every file in this folder, including the hidden `.nojekyll` file. Keep `index.html` at the top level, not inside a subfolder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
5. After a minute or two the site is live at `https://<your-username>.github.io/<repository-name>/`.
